prose-deslop · 流程说明

把 AI 味去掉的九个步骤

四个开源项目融合成一套固定顺序。九步，两次测量，四遍不许合并的回读。 每次跑完交两个数，不交"现在读起来自然多了"。

流程

九步，固定顺序，不许跳步。左边一列是步骤号，中间一列写清这一步由谁执行。 节点的颜色只编码这一件事，因为整条流程里只有一步必须换一个空白上下文的 agent 来做。

9 步 · 1 条返回边 · 1 条分流 · 手写 SVG

这张图只编码了两件事，其余都是标签。第一件事是次数。文本被改一次，测量两次， 中间隔着一个必须换上下文的审计。第二件事是回读分四遍且不许合并，因为它们看见的东西不同。 A 看保护片段有没有漂，B 看你自己刚写下的替换文字，C 看残留，D 看两处修改之间的接缝。

第二件事是有代价的。B 和 D 命中意味着回到 07 重改，而不是在 08 里就地修补。 在本次实跑里，这条返回边用了七次。

步骤

九步，每一步写清楚进什么，做什么，出什么，以及这一步是哪个上游项目贡献的。

01入口判定

该不该改这段文本

不是所有文本都该进这套流程。三种情况直接退回：

  • 要逐字翻译，要仿官方模板，要仿特定品牌 voice
  • 主体是代码、日志、命令、配置、接口名、报错
  • 要的是事实校对，不是风格改写

来源 说人话 · When to use

02判场景

它决定合格标准是什么

六个场景选一个：chat status docs public-writing academic code-context。场景不是标签，它直接决定这篇文本改到什么程度算对： chat 的标准是"会对朋友这样说吗"，学术的标准是一份好方法章节。

把聊天的标准套到论文上，出来是一摊烂泥。把文档的标准套到聊天上，出来是一个又冷又硬的客服。 场景判错，后面每一步都偏。

来源 说人话场景层 + deslop 语域基准 + natural-talk 朋友测试。本项目新增 academic 场景与论文包

03划保护片段

动手之前先冻结

冻结的内容分五类：

  • 数字、日期、版本、区间、单位
  • 引号内原文
  • 命令、参数、字段、路径
  • 报错、状态码、指标
  • 责任归属

还要单独记一份关系账本，这层没有任何词表能替代。哪个数字修饰哪个对象，谁做了什么，什么基于什么。 同段共现不等于存在这个关系。原文谓词里找不到依据的，改写里就不许有。

来源 说人话 protected spans + 关系账本

04前测

读数存档

measure.py --scene <场景>，读数存成 JSON。步骤 09 要和它对照，这是整条流程里唯一能证伪的部分。

指标分三层，判定权力不同。GATED 归零，CAPPED 只管超出部分，REPORTED 永不判定。见下一节。

来源 deslop 前后指标 + natural-talk 数值上限 + 说人话 residual 统计

05词面扫描

脚本只做便宜的一半

中文先扫物理动词，例如 跑一遍 抓到 压掉 落地 收口。 问一句就够了。这个画面是不是替代了句子本该说出的那个操作。英文先扫抬高词，例如 utilize facilitate commence。

再过 570 行词表。词表出的是候选，不是判决。下面这些它一个也认不出来：

  • 引用，以及统计学里的 robust
  • 戏剧化收尾
  • 节奏过匀
  • 只会叙述阅读路径的标题
  • 一套贯穿全文并且替代了说明的比喻
  • 写给在场者的注释和界面文案（taxonomy M）。这一族里一个标记词都没有

来源 deslop 物理动词 sweep + 四家词表合并去重

06逐行审计

唯一必须换一个空白上下文的一步

逐行对着标记表检查一遍，一行一条命中，宁可多报。表有六列，依次是位置，原句，族， 为什么这是表演而不是陈述，平替，留不留。

必须换上下文。写的那个 agent 审不了自己写的东西，它重读的是自己的意图， 不是纸面上的字。这一点对人和对 agent 一样成立，所以实现成一句硬要求， 审计跑在一个空白上下文的子会话里。

来源 deslop 审计表 + fresh-context subagent

07应用替换

文本只在这一步被改

换成字面动作。禁止用另一个花哨词换掉这个花哨词。这是最容易犯的错， 而且往往是刚写完这条规则的人犯的。

处理压缩标点会改变文本结构。句子拆开，行内枚举变成真列表，段落分节， 冒号背后藏着的小标题也要写出来。结构本身就是问题，所以这在范围内；文本主张什么不在范围内。

来源 deslop 压缩标点 + 说人话 scope 三档

08四遍回读

抓的东西不同，不许合并

A 保真。保护片段有没有漂，信息有没有丢，语域是否统一，术语是否失真，有没有生硬断裂， 以及分析与输出是否一致。

B 矫枉过正。书面词有没有变口语，双音节动词有没有变单音节，标题有没有变口语疑问句， 学术里的 hedge 有没有被改强。最要紧的一条是这个。把整套规则重新对着你自己刚写下的替换文字检查一遍。

C 残留。固定只查五类。残留开场，空收尾，旁白，空泛判断，节奏过匀。

D 整篇通读一遍。前三遍都逐条走，看不见两处修改之间的接缝。两段各自都对，中间断掉。 下决心更仔细没有用，仔细产生不了第二次阅读，只有另一种 pass 能。

来源 说人话两遍回读 + deslop 过校正 pass 与整篇通读

09后测与报告

交数，不交形容词

再跑一次 measure.py，然后交四样东西。前后指标对照表；每一个还留在表上的命中， 逐条写明为什么留；bounded scope 下的建议删除清单；缺依据的地方标出来。

"破折号 38 → 0"是证据。"现在读起来自然多了"不是。

来源 deslop 可证伪指标 + 说人话输出合同

指标分层

三层指标的判定权力不同，这是 measure.py 报告里的原始分层。 一条指标只有在"命中基本都是真的"时才配进计数集；实测说不是，就降级，并且把理由写在下一个人会读到的地方。

Gated

归零，或逐条具名

没有中间地带。

  • 破折号
  • 对偶反转
  • 顿号
  • 句中冒号
  • 助手残留
  • 知识截止免责
  • 表情符号
  • 内联标题列表
  • -ing 假分析
  • 系动词回避
  • 假区间
Capped

上限之内合法

只有超出的部分算问题。

  • 路标词
  • 自我评价
  • 讲义腔
  • 感叹号
  • hedge 堆叠
  • 句内加粗
  • 上限来自 natural-talk 的 300–500 字回复基准，长文按同一比例折算成密度。
Reported

只打印，不判定

给人看，永不参与判定。

  • 句长变异系数
  • 连词密度
  • 名词化
  • 借喻场混用
  • 三件套候选
  • 词表命中数

被降级的三条

降级是这套流程的证据标准在起作用，不是妥协。三条降级理由都印在每一份测量报告里，防止有人悄悄装回去。

  1. 三件套列举。这个问题是真的，指标不是。deslop 扫的第一份文档上，5 处命中全是正常枚举。 一个你不能信的数字，比没有数字更糟。
  2. 连词密度。说人话在 95 条语料上实测，判据反了。不该改的那组中位数 5.26/千字， 高于该改的那组的 0.00，最大值也更高。一对同密度用例把它钉死。叙事帖 80.00 该删一半， 迁移文档 81.08 一个都不能删。全局阈值会优先误伤技术文本。
  3. 整句加粗。这一条是在本次实跑里当场降级的。第一遍后测报了 11 处违规， 逐个看下去，9 处是带标签的列表，1 处是引文里别人的加粗。修好计数器之后又发现： 它抓不到真正的毛病（8 处整句加粗做强调），而整句加粗和加粗标签在形状上完全一样，只有语义能区分。 所以它和拟人一样，只进审计表，不进计数集。

句子变多，字数变少，这是解压缩的特征，不是删减。38 个挂在破折号上的从句变成了句子，同位语，或者括号， 多出来的连接材料跟着一起走了。连词密度反而升高。把一个破折号从句拆成两句，有时需要一个原来由破折号隐式承担的显性连词。 如果这条指标有判定权，它会惩罚这次修复本身。

更值得看的是回读抓到的东西。B 和 D 改掉了七条我自己的判断。两条是我矫枉过正 （删掉一个带 hedge 的自评，等于把作者没下的论断改强了；把"绝大多数" softening 成"大多数"， 等于把别人测出来的量级抹糊了），两条是我在删修饰的同时把作者的论断收窄了， 还有三条是我自己拆句造成的接缝损坏。一处指代失效，一处并列形式被破坏，还有一处同一个短语连着出现两次。 逐行的两遍一处都没看见。
